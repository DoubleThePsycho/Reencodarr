# <img width="24px" src="./Logo/256.png" alt="Reencodarr"></img> Reencodarr

Reencodarr is a self-hosted media transcoding, remuxing, and normalization manager built around FFmpeg and the *arr ecosystem.

The project is being rebuilt on the current Sonarr codebase, using Sonarr's mature application infrastructure and frontend as the baseline while Reencodarr-specific functionality is reintroduced deliberately and validated incrementally.

The current branch should remain as close to upstream Sonarr as practical. Differences from upstream must exist for a specific Reencodarr requirement rather than being inherited automatically from an earlier implementation.

## Status

Reencodarr functionality is currently being integrated into the Sonarr-derived baseline.

Previously validated Reencodarr implementations remain reference material only. Features are not considered part of this branch until they have been deliberately ported and revalidated here.
